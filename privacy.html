Privacy Policy

Last updated: 29 September 2026

Worklog AI is a personal automation tool used only by its owner. It is not offered to the public.

What it accesses

  • Google Calendar: reads the owner's events to build a personal work log, and creates focus-time events for learning.
  • Gmail: reads only emails under a single label chosen by the owner. It does not send, change or delete emails.

How data is used and stored

  • All data is processed on the owner's own computer, including by a locally running AI model.
  • The work log is stored in a file on the owner's computer.
  • Short reminders about the owner's own learning tasks are sent only to the owner through a private Telegram bot.
  • Data is never sold, shared with third parties, or used for advertising.

Google API data

Worklog AI's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions, and the local log file can be deleted at any time.
